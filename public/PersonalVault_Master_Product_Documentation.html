2. Product Philosophy & Core Objectives

2.1 The Sovereign Data Problem

Modern individuals must safeguard highly sensitive records: Government Identity cards, doctor prescriptions, lab blood reports, product warranty invoices, and digital credentials. Conventional cloud services (Google Drive, Dropbox, 1Password, Bitwarden) rely on centralized company databases where third-party servers hold master decryption metadata, making user records vulnerable to corporate surveillance, AI model training, and catastrophic cloud breaches.

2.2 The Sovereign Vault Solution

Personal Vault operates on the principle of Zero-Knowledge by Construction:

  • Zero Developer Servers: Personal Vault runs 100% locally on the user's client device. Zero server APIs, zero analytics cookies, zero tracking pixels.
  • Client-Side Cryptography: All encryption, decryption, and key derivation take place strictly inside the user's device memory using WebCrypto and native OS Hardware Enclaves.
  • Absolute User Sovereignty: Even under subpoena, developers cannot decrypt or produce user data because no user data ever reaches the developers.

5. Step-by-Step User Operations Handbook

Journey 1: Creating Your Master Vault

  1. Launch Personal Vault and enter your Display Name.
  2. Review the 3 Core Pillars slideshow and click Continue.
  3. Set a strong master passphrase (minimum 8 characters).
  4. Crucial Step: Copy your 256-bit Emergency Recovery Key and store it safely offline. Check the confirmation box and enter your vault.

Journey 2: Adding a Prescription for a Child

  1. Navigate to Medical & Health Records → Click + Add Prescription.
  2. In the Patient dropdown, select your child (e.g. 👶 Aarav).
  3. Enter the doctor, diagnosis, and prescription date.
  4. Attach the prescription photo or use Snap & Auto-Fill to extract text.
  5. Click Save Prescription.

Journey 3: Upgrading to Pro

  1. Upon reaching 10 items, the Pro Upgrade Modal will open.
  2. Click Get Pro License to pay via Razorpay (https://razorpay.me/@bssdinesh).
  3. Check your email for your MLD-PRO-... license key.
  4. Paste the key into the activation modal and click Activate Pro License.

6. Administrator & Operator Manual

Admin Task 1: Generating Offline Pro License Keys

cd app
node scripts/generate-license.cjs "Customer Name" "customer@gmail.com" "lifetime"

Admin Task 2: Free Automated License Mailer Setup

  1. Open Google Apps Script (https://script.google.com) and create a project.
  2. Paste the contents of app/scripts/razorpay-auto-mailer.gs.
  3. Deploy as a Web App (Access: Anyone) → Copy the Webhook URL.
  4. In Razorpay Dashboard → Settings → Webhooks: Add the URL with events payment.captured and order.paid.

Admin Task 3: Building Signed Android App Bundle (.aab)

  1. Run keytool -genkey -v -keystore personal-vault-release.keystore -alias personalvault -keyalg RSA -keysize 2048 -validity 10000.
  2. Run npx cap open android → Android Studio: Build → Generate Signed Bundle / APK → Android App Bundle.
  3. Upload the generated .aab file to Google Play Console.

7. Technical Specifications & Data Dictionary (Annexures)

Annexure A: Cryptographic Standards

  • Symmetric Encryption: AES-256-GCM (Galois/Counter Mode) with 128-bit authentication tag and 96-bit unique IV per record.
  • Key Derivation: PBKDF2-HMAC-SHA256 with 100,000 iterations and 128-bit cryptographically secure random salt.
  • Offline License Verification: HMAC-SHA256 digital signature over base64 JSON payload.
