🛡️ 1. Privacy Shield Security & Multitasking Lock Engine

MyLifeDock v1.2.0 restores and fortifies vault privacy across mobile and desktop multitasking environments:

  • Native App Backgrounding (Capacitor AppState): Listening to appStateChange. Whenever the user taps Home, navigates away, or enters the task switcher, the vault locks immediately.
  • Web & Desktop Minimized Watchdog: Dispatches instant lock when document.hidden === true on window minimization or tab switching.
  • Android Window Manager FLAG_SECURE: Active in MainActivity.java, rendering blank preview thumbnails in the Recent Apps carousel and blocking third-party screen recorders.
  • Brute-Force Rate Limiting Lockout: Progressive countdown penalty (5s, 15s, 30s) on consecutive failed attempts with disabled inputs and live countdown badges.
  • Configurable Inactivity Auto-Lock: User-customizable timeout options (1m, 5m, 15m, 30m default, 60m) under Settings.

👁️ 2. Universal Typography & Visual Ergonomics Overhaul
