How to…

Start a discount offer
  1. Open the Pricing tab of the MyLifeDock Orders sheet.
  2. On the plan's row: tick the Offer on checkbox (a real tick, not typed text).
  3. Offer price ₹: a whole number lower than Price ₹ (e.g. 199 for Lifetime 999 is fine; 999 or more is ignored).
  4. Offer text: e.g. "Diwali offer" (shown on the website).
  5. Offer ends (last day): today or a later date, or leave it empty for no end.
  6. Wait one minute, then press Refresh above. The plan should say "Offer on".

The website, the Windows app and the Razorpay checkout all use the offer price. It stops by itself after the last day.

Backup Payment Pages keep their fixed amount (they are only used if the main checkout is down). Buyers there get the plan of the amount they paid.

Change a regular price
  1. Change Price ₹ (and Price $ if needed) in the Pricing tab. Live in about a minute.
  2. Razorpay → Payment Pages: change that plan's backup page amount to match.
Someone paid but did not get a key
  1. Ask them to check spam for "Your MyLifeDock Pro license key".
  2. Look for their row in the Orders sheet. If it is there, copy the License Key and resend it (Admin tool → Inspect key, or a normal Gmail reply).
  3. No row? Check Razorpay → Payments that it is Captured, then Apps Script executions for an error.
  4. Issue one by hand: Admin → Issue key, enter the email and plan, Send via Gmail (paste with Ctrl+V, Send), then Copy row and paste it into the Orders sheet so it is on record.
Refund a payment
  1. Razorpay → Payments → open the payment → Refund.
  2. Write "Refunded" next to the order in the Orders sheet.

Keys work offline, so a refunded key cannot be switched off remotely. That is why refunds are limited to 7 days.

Send renewal reminders
  1. Orders sheet → File → Download → Comma-separated values (.csv).
  2. Admin tool → Import orders CSV. "Renewals to follow up" lists plans ending soon, each with an email button.
Update the Apps Script (after a code change)
  1. Copy all of scripts/razorpay-auto-mailer.gs and paste it over the code in the MyLifeDock-License-Mailer project. Save.
  2. Deploy → Manage deployments → pencil → Version: New version → Deploy. The URL stays the same.
  3. Press Refresh above to check that it still answers.
Open this hub and the Admin tool quickly
  • Bookmark this page in Chrome or Edge (Ctrl+D). The Admin tool needs Chrome or Edge for the one-click "remember my key".
  • First time in the Admin tool: Choose key file and remember it → pick %USERPROFILE%\.mylifedock\license-signing-private-key.pem. Later: Open with my saved key.
Keep things safe
  • Never send or upload the .pem signing key. Keep a copy on a USB stick or offline drive: if it is lost, no new keys can be made for existing app versions.
  • Razorpay key secret lives only in Apps Script → Script Properties.
  • The tools/ folder is for your computer only; it is not part of the website.
