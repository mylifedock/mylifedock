Prices and offers: one place

Open your MyLifeDock Orders Google Sheet → Pricing tab. Change Price ₹, or tick Offer on with an Offer price ₹, Offer text and Offer ends date.

  1. Within about a minute the website, its checkout and the Windows app show the new price or offer, and Razorpay charges it.
  2. License emails give the right plan automatically, including during offers.
  3. Offers switch off by themselves after the end date. An offer price must be below the regular price, otherwise it is ignored.
  4. Android and iPhone prices are set in Google Play Console and App Store Connect.

If you change a regular price for good, also update the backup Payment Page amount in Razorpay (used only if Google is unreachable) and, at the next release, the built-in prices (npm run release:check lists every place).

Automatic license emails (Apps Script)

  1. Checkout runs on the website (buy.html); the backup Payment Pages collect Email, Phone and a Name field.
  2. Your Apps Script project contains scripts/razorpay-auto-mailer.gs (pasted directly). Run setupOrdersSheet once from the editor: the log prints the link to the "MyLifeDock Orders" sheet that every order is written to.
  3. Script Properties: RAZORPAY_KEY_ID, RAZORPAY_KEY_SECRET, MLD_LICENSE_PRIVATE_KEY.
  4. Deployed as a Web app (Execute as: Me, Anyone). After changing the script: Deploy → Manage deployments → Edit → New version.
  5. Razorpay → Account & Settings → Webhooks: the Web app URL with the event payment.captured.
  6. Health check: the Web app URL followed by ?action=pricing shows the prices; a test purchase adds a row to the sheet and sends the email.

Privacy of this tool

Orders you import and keys you issue stay in this tab's memory and disappear when you close or lock it. Nothing is sent anywhere. If you chose "remember", the browser keeps only the location of the key file (not the key) and asks before reading it; "Forget" on the unlock screen removes it. Keep the signing key file and exported CSVs out of the repository and out of shared folders.
